01 O que é o Gerador de Cubos

É um programa de computador para olhar os seus dados por vários ângulos ao mesmo tempo — sem fórmulas e sem programação.

Imagine uma planilha de vendas com centenas de linhas. Sozinha, ela só mostra transações. O cubo analítico agrupa essas linhas automaticamente e responde perguntas como “Quanto cada produto vendeu, mês a mês?” ou “Qual vendedor tem o maior ticket médio?”. Você monta a pergunta arrastando campos com o mouse e a resposta aparece na hora, em tabela e em gráfico.

CSV
Entra uma planilha simples (o arquivo que o Excel exporta)
🖱️ Arrastar
Você monta a análise soltando campos em 4 áreas
📊 Decidir
Sai uma tabela com totais, gráficos e Excel pronto
💡
Não é preciso saber nada de banco de dados. Se você usa uma planilha, você já sabe o suficiente para usar este programa.

02 Abrir o programa

O Avesso abre em uma janela própria no Windows — como qualquer programa. Não precisa instalar nada e não precisa de internet.

  1. Descompacte o arquivo

    Abra o Avesso.zip que você baixou e extraia para uma pasta à sua escolha. Vai aparecer uma pasta chamada Avesso.

  2. Dê um duplo-clique no Avesso.exe

    Dentro da pasta Avesso, é só clicar duas vezes no programa.

  3. Pronto: a tela de Importação abre

    Uma janela se abre direto na tela Importação. É por aqui que todo trabalho começa.

Na primeira vez: o aviso azul do Windows

Por ser um programa novo (ainda sem assinatura digital paga), na primeira vez o Windows pode mostrar uma tela azul de segurança, o Defender SmartScreen. É normal e seguro — é o seu próprio programa. Para liberar, são dois cliques:

🛡️
Clique em “Mais informações” e depois no botão “Executar assim mesmo”. O Avesso abre e você só precisa fazer isso uma vez por computador.
💡
Prefere usar no navegador (mais leve)? Dê um duplo-clique no Abrir no navegador.bat — veja a seção 10. E para só experimentar, toda a tela de importação tem um botão Carregar exemplo com uma planilha de vendas pronta. Vamos usá-la neste manual. Essa planilha também está como arquivo na pasta data, ao lado do programa — junto com um cubo de exemplo pronto (.cubo, que mostra como dois vendedores chegam a um faturamento parecido com esforços bem diferentes) e os scripts SQL de exemplo, caso queira abri-los direto.

03 Importar os dados — passo a passo

Quatro passos curtos: escolher o arquivo, conferir a leitura, olhar a prévia e dizer o que é cada coluna.

  1. Escolha o arquivo

    Clique em Selecionar arquivo… e aponte para o seu .csv. Para treinar, clique em Carregar exemplo.

  2. Confira a leitura (quase sempre automática)

    Os campos Delimitador, Separador decimal, Separador de milhares e Codificação já vêm em “Detectar automaticamente”. Deixe assim na primeira tentativa.

    Clique no botão Analisar.

  3. Olhe o resumo e a pré-visualização

    Aparece o Resumo da leitura (quantas linhas e colunas) e a Pré-visualização com as primeiras linhas. Bateu com o que você esperava? Siga em frente. Se os acentos saírem errados ou os números virarem texto, troque a Codificação ou o Separador decimal e clique em Analisar de novo.

  4. Confirme o que é cada coluna

    No quadro Identificação dos campos, cada coluna recebe um papel sugerido:

    📐 Dimensão
    Serve para agrupar: Produto, Vendedor, Cliente, Mês.
    Σ Métrica
    Serve para somar/contar: Valor total, Quantidade.

    Você pode ajustar o nome de exibição, o tipo e o papel de qualquer coluna. Quando estiver certo, clique em Confirmar campos para abrir o construtor de cubos.

    📅
    Formato da data. Quando uma coluna é do tipo Data, aparece logo abaixo um seletor de formato de exibição: dd/mm/aaaa, dd/mm/aaaa hh:mm:ss, aaaa-mm-dd e outros. Escolha como quer ver a data — e fique tranquilo: ela continua sendo data, ou seja, continua ordenando em ordem cronológica e gerando os campos (Ano)/(Mês)/(Ano-Mês) certinho.
⚠️
Códigos não são números. CEP, CPF, código de cliente ou “007” parecem número, mas você nunca vai somar um CEP. O programa já deixa esses casos como Dimensão — mantenha assim. Só devem ser Métrica as colunas que faz sentido somar ou tirar média.
Precisa mesmo somar (ou tirar média, mínimo…) um campo numérico que ficou como Dimensão? Sem problema: no cubo, você ainda consegue arrastá-lo para Métricas assim mesmo.

04 Trazer dados de um banco (MySQL, SQL Server ou PostgreSQL)

Além de arquivos CSV, o cubo conversa direto com um banco de dados — MySQL, SQL Server ou PostgreSQL — de forma nativa, sem precisar instalar driver nem configurar aquela “Fonte de Dados ODBC” do Windows. Você escreve uma consulta e os registros entram no cubo na hora.

Passo a passo

  1. Na tela de importação, clique em 🔗 Conectar a um banco. Abre a janela de conexão.
  2. Em Tipo de banco, escolha MySQL, SQL Server ou PostgreSQL. A Porta se ajusta sozinha (3306 para MySQL, 1433 para SQL Server, 5432 para PostgreSQL).
  3. Preencha os dados de acesso:
    • Servidor — o endereço do banco (ex.: 127.0.0.1 ou localhost se for na sua máquina). No SQL Server com instância nomeada, use SERVIDOR\INSTANCIA;
    • Porta — já vem preenchida; só mude se o seu banco usa outra;
    • Tipo de autenticação só no SQL Server — escolha como entrar:
      • Autenticação do Windows — entra com o seu próprio login do Windows (conexão confiável). Os campos Usuário e Senha ficam desligados: você não digita nada;
      • Autenticação do SQL Server — entra com um usuário e senha criados dentro do SQL Server.
    • Usuário e Senha — o seu login do banco (no MySQL e no PostgreSQL sempre; no SQL Server, apenas quando escolher Autenticação do SQL Server);
    • Banco de dados — o nome do banco onde estão as tabelas.
  4. Clique em Testar conexão. Se tudo estiver certo, aparece em verde a versão do servidor. Se não, aparece em vermelho o motivo (usuário/senha errados, servidor fora do ar…), para você corrigir.
  5. Escreva sua consulta SELECT na caixa de SQL e clique em Trazer para o cubo.
  6. Os registros caem na mesma tela de conferência de campos que você já conhece (tipo e papel de cada coluna). Ajuste se quiser e clique em Confirmar campos. Pronto — o cubo está montado sobre os dados do banco.

A janela de consulta — um mini-editor de SQL

A caixa onde você escreve o SELECT é um editor com cores: palavras-chave, textos e números ganham destaque, como num editor de verdade — ajuda a escrever e a revisar. No cabeçalho da caixa há o botão ⤢ maior, que amplia a janela e deixa o editor ocupar quase a tela inteira (ótimo para consultas grandes); clique de novo (⤢ restaurar) para voltar ao tamanho normal.

⚠️
Consulta sem WHERE? Se você mandar um SELECT sem filtro, o programa avisa que ele pode trazer muitas linhas e pergunta se quer continuar. É só um lembrete — você decide: OK para seguir mesmo assim, ou Cancelar para incluir um WHERE antes.
✏️
Mudou a consulta depois? Já na tela do cubo, o botão 🔎 Editar consulta (na barra de cima — aparece quando os dados vieram de um banco) reabre a janela já preenchida com a sua conexão e a consulta atuais, inclusive a senha (guardada só na memória da sessão, nunca em disco). Ajuste o SQL, clique em Aplicar consulta e o cubo recalcula — e, se as colunas continuarem as mesmas, ele até mantém a sua montagem.
💡
Quer experimentar sem ter um banco pronto? Na pasta data do programa há três scripts de exemplo: vendas_exemplo_mySql.sql (MySQL), vendas_exemplo_sqlServer.sql (SQL Server) e vendas_exemplo_postgres.sql (PostgreSQL). Rode o do seu banco — ele cria as tabelas vendedor, produto, cliente e venda com as 400 vendas do exemplo. Depois, use esta consulta (vale nos três) para reproduzir exatamente o cubo deste manual:
SELECT v.data_venda, vd.nome AS vendedor, p.nome AS produto,
       c.nome AS cliente, v.quantidade, v.valor_total
FROM venda v
JOIN vendedor vd ON vd.id = v.vendedor_id
JOIN produto  p  ON p.id  = v.produto_id
JOIN cliente  c  ON c.id  = v.cliente_id;

São as mesmas 400 vendas da planilha de exemplo, agora vindas do banco — os números batem igualzinho.

✅
Só leitura, por segurança. A janela aceita apenas consultas que lêem dados (SELECT, WITH, SHOW…). Comandos que alteram o banco — INSERT, UPDATE, DELETE, DROP — são recusados. O objetivo é trazer registros para analisar, nunca mexer no seu banco.

SQL Server não conecta? (mas no Management Studio funciona)

Essa é a dúvida mais comum — e quase sempre tem a mesma explicação. O Management Studio, por rodar na mesma máquina, conecta por um atalho interno (memória compartilhada) que não usa a rede. Já o Gerador de Cubos conecta por TCP/IP, como qualquer programa externo faria. E no SQL Server Express o TCP/IP costuma vir desligado de fábrica — por isso o SSMS entra e o app, não. Não é erro seu: falta ligar o TCP/IP no servidor, uma única vez.

  1. Abra o SQL Server Configuration Manager (Gerenciador de Configuração do SQL Server).
  2. Vá em Configuração de Rede do SQL Server → Protocolos do [sua instância] (ex.: SQLEXPRESS).
  3. Clique com o botão direito em TCP/IP e escolha Habilitar.
  4. Abra as Propriedades do TCP/IP → aba Endereços IP → role até IPAll:
    • Portas TCP Dinâmicas: apague o conteúdo (deixe em branco);
    • Porta TCP: digite 1433.
  5. Em Serviços do SQL Server, clique com o direito no seu SQL Server (sua instância) e escolha Reiniciar.

Pronto. Agora, na janela de conexão, use Servidor localhost, Porta 1433 e preencha o resto normalmente.

💡
Prefere não fixar a porta? Dá para usar a porta dinâmica: habilite o TCP/IP e inicie o serviço “SQL Server Browser”; então, no campo Servidor, escreva SERVIDOR\INSTANCIA (ex.: localhost\SQLEXPRESS). Ainda assim, a porta fixa 1433 é o caminho mais simples e confiável — é a nossa recomendação.
⚠️
Outras causas possíveis. Se o TCP já estiver ligado e mesmo assim não conectar: confira se o serviço do SQL Server está em execução; se o banco é em outro computador, verifique o firewall na porta 1433; e confirme o tipo de autenticação — para entrar com usuário e senha, o SQL Server precisa estar no modo de autenticação “SQL Server e Windows” (Modo Misto).

Quer usar usuário e senha do SQL Server?

A janela oferece dois tipos de autenticação para o SQL Server. A Autenticação do Windows funciona de imediato quando o banco aceita o seu login do computador. Já a Autenticação do SQL Server — entrar com um usuário e senha criados dentro do banco — exige dois preparos no servidor, feitos uma única vez:

  1. Ligar o Modo Misto. No Management Studio, clique com o botão direito no servidor → Propriedades → Segurança → marque “SQL Server and Windows Authentication mode” (Modo Misto) → OK. Depois reinicie o serviço do SQL Server (igual você fez com o TCP/IP).
  2. Ter um login com senha. O login sa vem desabilitado no SQL Express. No Management Studio, em Segurança → Logins, abra o sa (ou crie um login novo), defina uma senha forte e, na aba Status, marque Login: Habilitado.

Feito isso, na janela de conexão escolha Tipo de autenticação → Autenticação do SQL Server e informe esse usuário e senha.

⚠️
Se aparecer “Login failed for user…”, quase sempre é um destes dois: o Modo Misto ainda está desligado (ou o serviço não foi reiniciado), ou o login está desabilitado / a senha está errada.
💡
Qual escolher? Se o banco está na sua máquina ou na rede da empresa, a Autenticação do Windows costuma ser a melhor: entra com o seu próprio login, sem criar nem guardar senha (e o cubo salvo nem pede senha ao reabrir). Use usuário e senha do SQL Server quando precisar de um acesso que não é o seu usuário do Windows — por exemplo, um login só para relatórios.

Atualizar e salvar

  • Atualizar dados (🔄, na barra do cubo) re-executa a consulta e traz os registros mais recentes do banco — perfeito quando os dados mudam ao longo do dia. A data da última carga aparece ali do lado.
  • Salvar cubo guarda a montagem, a sua consulta, os dados da conexão (tipo de banco, servidor, usuário, banco) e os próprios dados daquela carga — mas nunca a senha. Por isso, ao reabrir, o cubo aparece na hora com os dados salvos, sem pedir senha e sem reconsultar o banco. A senha só é pedida quando você clica em Atualizar dados para buscar os registros mais recentes (na Autenticação do Windows nem isso: ele usa o seu login). Assim seu acesso ao banco fica seguro mesmo que você compartilhe o .cubo.
⚠️
Consulta muito grande? Se o SELECT trouxer um volume enorme de linhas, o cubo carrega as primeiras e avisa — refine com um WHERE (ou LIMIT no MySQL e no PostgreSQL / TOP no SQL Server) para trazer só o que interessa. Cubos ficam mais rápidos e claros com os dados já filtrados na origem.

05 As 4 áreas do cubo

Esta é a tela principal. À esquerda ficam os Campos disponíveis; é só arrastá-los para as quatro áreas. Os campos que são números de somar (as métricas) vêm marcados Σ em verde — o Σ (a letra grega de “soma”) e o verdinho são o seu atalho visual: verde = dá para somar.

▽ Filtros
Recorta a análise. Ex.: só um ano, ou tirar um cliente da conta. Ano = 2025
⋯ Colunas
Vira cabeçalho na horizontal. Ótimo para o tempo. Data da venda (Mês)
⋮ Linhas
Vira as linhas da tabela — o “por quem” você quer ver. Produto
Σ Métricas
O que é calculado em cada cruzamento. Soma de Valor total

A regra é simples e sempre a mesma:

✅
Linhas × Colunas definem como os dados são agrupados. Métricas definem o que é calculado em cada célula. Filtros definem o que entra na conta.
💡
Um campo pode ficar em Linhas (ou Colunas) e em Filtros ao mesmo tempo. É assim que você diz "quebre por Vendedor, mas mostre só estes vendedores": ponha Vendedor em Linhas e em Filtros, e no filtro desmarque quem não quer ver. (O que não combina é o mesmo campo em Linhas e Colunas juntas — aí ele troca de lugar.)

Datas já vêm “fatiadas”

Ao confirmar os campos, cada coluna de data ganha automaticamente três campos extras: (Ano) (Mês) (Ano-Mês). Assim você agrupa por período sem precisar mexer na planilha original. E, em qualquer área, as datas aparecem em ordem cronológica — não alfabética.

Mais espaço para a análise

Com o cubo montado e você querendo só olhar o resultado, clique em ▲ Esconder configuração (na barra de cima): as áreas de campos somem e a tabela ganha a tela toda. Para mexer de novo, clique em ▼ Mostrar configuração. E logo acima da barra, o nome do cubo em edição fica sempre à vista — ou “cubo não salvo” enquanto você ainda não salvou.

💡
Com pressa? O botão Cenário do exemplo monta uma análise inicial sozinho, para você ver o cubo funcionando. E Limpar áreas zera tudo para começar do seu jeito.

06 Métricas, subtotais e totais

Cada métrica é um campo + uma forma de calcular. Você pode ter várias ao mesmo tempo.

Ao arrastar um campo numérico para a área Métricas, escolha como ele é agregado:

Soma Média Contagem Contagem distinta Mínimo Máximo

💡
“Contagem” conta quantas linhas caíram no grupo (ex.: quantos pedidos). “Contagem distinta” conta valores diferentes (ex.: quantos clientes diferentes compraram). Essa diferença muda a leitura — escolha com atenção.

O cubo calcula sozinho os subtotais de cada nível, o total por coluna e o total geral. Para ligar as ajudas visuais, use as caixas no topo: ☑ Barras (barras proporcionais dentro das células) e ☐ Mapa de calor (cores do menor ao maior valor). Clique no cabeçalho de uma métrica para ordenar por ela.

Métrica calculada: monte a sua própria fórmula

Às vezes o número que você precisa não está na planilha — ele nasce de uma conta entre números que já existem. O clássico é o preço médio (receita ÷ unidades), mas você pode montar qualquer fórmula: ticket médio, margem, participação, o que for. E o melhor: só clicando, sem digitar nada de código.

  1. Clique em “÷ calculada”

    No cantinho da área Métricas tem o botão ÷ calculada. Clique nele — abre o montador de fórmula.

  2. Monte a fórmula clicando nos botões

    A fórmula vai se formando numa tira, peça por peça. Você tem botões para tudo:

    • + métrica: escolhe como somar (Soma, Média…) e qual campo, e insere. (as métricas entram verdes)
    • + − × ÷: os operadores. ( e ): parênteses, para mandar na ordem das contas.
    • + número: insere um número fixo (ex.: 100 para virar porcentagem).
    • ⌫ apaga a última peça; limpar zera tudo. Clicar numa peça da tira também a remove.

    Embaixo da tira aparece um ✓ a fórmula pronta (ou um aviso do que falta). O botão Adicionar só acende quando a fórmula está completa — impossível errar a sintaxe.

  3. Dê um nome e pronto: virou coluna

    Escreva um Nome (ex.: Preço médio), escolha o Formato e clique em Adicionar. Surge a coluna ƒ Preço médio — para o Mouse dá R$ 70; para o Teclado, R$ 119. Precisa ajustar? Clique no lápis ✎ do chip.

💡
Exemplos que valem ouro: Preço médio = Valor total ÷ Quantidade; Margem % = (Valor total − Custo) ÷ Valor total × 100; Ticket médio = Valor total ÷ Contagem de pedidos.
O pulo do gato está no total: o cubo refaz a conta em cada célula — linha, subtotal e total. Por isso o total é a média ponderada (ex.: receita total ÷ unidades totais), e não a média solta das linhas.

Modo relatório: ver os registros, sem somar

Nem toda análise precisa de soma. Às vezes você quer só listar os registros, como um relatório. Para isso, não coloque nada em Métricas: arraste as colunas que quer para Linhas (ex.: Data da venda, Vendedor, Produto) e o cubo mostra cada registro, exatamente como você escolheu, sem agrupar nada. Assim que você adicionar uma métrica, ele volta a somar normalmente.

📋
No relatório, clique no cabeçalho de uma coluna para ordenar por ela (uma vez A→Z, de novo Z→A), com datas em ordem cronológica. É a listagem completa — sem limite de linhas.

Salvar, reabrir e atualizar o seu cubo

Montou um cubo que vale a pena guardar? Na barra de cima há três botões para isso:

💾 Salvar cubo
Abre a janela Salvar como do Windows — você escolhe o nome e a pasta. Guarda a montagem (linhas, colunas, filtros, métricas e fórmulas) e os próprios dados daquela carga num arquivo .cubo. Ao salvar, aparece embaixo onde ele foi guardado.
📁 Abrir cubo
Abre um .cubo salvo e mostra os dados na hora, do jeito que estavam — sem reler a planilha nem reconsultar o banco (funciona até se o arquivo saiu do lugar). Dá para abrir já na tela inicial, em Abrir cubo salvo.
🔄 Atualizar dados
Quando quiser os números mais recentes, relê a origem (a planilha ou o banco) e recalcula — a montagem continua igualzinha. É a única ação que troca a data da carga.
💡
No canto direito da barra aparece Última carga: dia/mês/ano hora — o momento em que os dados foram realmente lidos da origem. Ela não muda quando você só reabre o cubo (são os mesmos dados que você salvou); só muda quando você clica em Atualizar dados. Assim você sempre sabe se está olhando números fresquinhos ou de uma carga antiga.
Como o .cubo agora guarda os dados dentro dele, o arquivo fica maior — em compensação, abre instantâneo e é autossuficiente.

07 Como ler o resultado

Uma tabela bonita não decide nada sozinha. O que decide é a comparação entre as linhas.

Três perguntas que você sempre deve fazer ao olhar um cubo:

1 ·
Quem concentra? Qual linha responde pela maior fatia do total?
2 ·
Quem destoa? Alguma linha com muito “esforço” (contagem) e pouco “resultado” (soma)?
3 ·
O que mudou? Olhando mês a mês nas colunas, o que subiu e o que caiu?

É exatamente isso que o próximo caso prático mostra, passo a passo.

Ordenar com um clique no cabeçalho

Para achar “quem concentra”, ordene a tabela — basta clicar nos cabeçalhos. Clique uma vez para uma direção, de novo para a outra; a setinha ▲▼ mostra qual ordem está valendo:

  • no nome da dimensão de linha (ex.: Vendedor) → ordena as linhas pelo rótulo, de A→Z ou Z→A. Datas saem em ordem cronológica e números na ordem numérica, não como texto;
  • no cabeçalho de uma métrica (ex.: Soma de Valor) → ordena as linhas por aquele número, do maior para o menor (ou o contrário). Se a métrica estiver dentro de uma coluna — por exemplo um mês específico — a ordem respeita aquela coluna.
🖱️
Linhas e colunas são ordenáveis. Clique no cabeçalho que te interessa e deixe o maior valor subir para o topo — é a forma mais rápida de responder “quem concentra?”.

Filtrar valores — com busca

Clique no chip de um campo na área Filtros para abrir a janela de valores. Quando o campo tem muitos valores, aparece um campo de busca: digite parte do que procura (ex.: Curitiba) e a lista vai filtrando enquanto você digita.

🔎
A regra é simples: deixe marcados só os valores que você quer ver no cubo e clique em Aplicar. Para escolher poucos itens, o caminho mais rápido é clicar em Nenhum (desmarca tudo), buscar e marcar só o que interessa. Os botões Todos e Nenhum valem para a lista inteira, mesmo com uma busca ativa na tela.

08 Caso prático: uma decisão de verdade

A equipe comercial bateu a meta de faturamento, mas o lucro não cresceu. A pergunta do dono: “Onde a minha equipe está gastando energia à toa — e onde deveria estar?”

Vamos responder isso com a planilha de exemplo (400 vendas, de janeiro a junho de 2025: Produto, Vendedor, Cliente, Quantidade e Valor total). Faça junto — os números abaixo são exatamente os que vão aparecer na sua tela, até os centavos.

🟢
Ponto de partida (faça uma vez): na tela inicial, clique em Carregar exemplo e depois em Confirmar campos. Pronto — você está na tela do cubo. Se já mexeu em algo, clique em Limpar áreas para começar do zero.

  1. Monte o cubo por produto (3 métricas)

    Arraste, na ordem:

    • Produto → área Linhas.
    • Valor total → área Métricas (entra como Soma de Valor total = a receita).
    • Quantidade → área Métricas (entra como Soma de Quantidade = unidades vendidas).
    • Valor total de novo → Métricas, e no seletorzinho do chip troque Soma por Contagem (vira Contagem de Valor total (nº de registros) = nº de pedidos, o “esforço” de venda).

  2. Crie o “Preço médio” (métrica calculada)

    Clique em ÷ calculada (no alto da área Métricas). Monte a fórmula clicando: + métrica → Soma de Valor total; botão ÷; + métrica → Soma de Quantidade. Dê o nome Preço médio e clique em Adicionar. (É o preço por unidade — a conta que antes você fazia na mão.)

  3. Ordene pela receita e confira (tem de bater!)

      • Contagem de Valor total — quantos pedidos ele fez;
      • Média de Valor total — o ticket médio (quanto rende cada pedido). Para criá-la, arraste Valor total para as Métricas mais uma vez e troque o seletor dela para Média.

    Os dois ângulos contam a mesma história. A análise não só confirmou a suspeita — ela apontou o que fazer:

    ▶ Plano de ação que saiu do cubo

    1. Redirecionar a prospecção para Notebook e Monitor (juntos, 77% da receita), que trazem retorno alto por atendimento.
    2. Tirar Mouse e Teclado do atendimento individual: vendê-los em kit junto com o notebook ou por um canal de autoatendimento, liberando mais de 40% dos pedidos para itens de maior valor.
    3. Replicar o método da Ana com a Carla: o problema não é volume de trabalho, é o mix vendido. Treinar para subir o ticket médio.

    A frase que faz tinir os ouvidos na reunião: “40% do nosso esforço rende menos de 5% da receita.” Troque metade desses pedidos por notebooks e o faturamento não cresce um pouco — ele muda de patamar. Isso não saiu de um palpite; saiu de dois cubos de 30 segundos.

10 Navegador ou desktop?

O Avesso roda de duas maneiras — a mesma tela e as mesmas funções, muda só o jeito de abrir. Cada uma tem o seu atalho (.bat), para você abrir com um duplo-clique.

Recomendado

🖥️ Aplicativo (janela própria)

Duplo-clique no Avesso.exe — abre numa janela de desktop (como qualquer programa).

  • Tem o seletor de arquivos do Windows no botão Selecionar arquivo….
  • Nada para instalar: usa o motor do Edge que já vem no Windows.
Mais leve

🌐 No navegador

Duplo-clique no Abrir no navegador.bat — ele liga o servidor e abre o seu navegador no Avesso, sozinho.

  • Funciona em Chrome, Edge ou Firefox e gasta menos memória (ótimo para PCs mais modestos).
  • Enquanto está aberto, aparece um ícone do Avesso na bandeja (ao lado do relógio): clique nele para reabrir a aba no navegador, ou use o menu Encerrar o Avesso para fechar o programa.
  • Única diferença: ao clicar em Selecionar arquivo…, abre o seletor de arquivos do próprio navegador (em vez do do Windows); salvar e abrir cubo também usam o download e o seletor do navegador. O resto é idêntico.
💡
Qual usar? Para a experiência de aplicativo, abra o Avesso.exe. Se o computador tem pouca memória ou você prefere o navegador, use o Abrir no navegador.bat. As duas formas fazem exatamente o mesmo trabalho.
🔒
Nos dois modos, tudo roda dentro do seu computador (endereço 127.0.0.1, a própria máquina): não precisa de internet e nenhum dado sai do PC — nem a planilha, nem os resultados.
⚠️
E se vários usuários, em computadores diferentes, quisessem acessar pela rede? Aí é outro cenário: hoje o Avesso lê os arquivos do próprio computador onde roda e atende um usuário por vez. Para virar um sistema web central (muitas pessoas acessando ao mesmo tempo, cada uma do seu PC), ele precisaria de ajustes — envio de arquivo (em vez de caminho), sessões separadas por usuário e segurança. É um passo à parte; converse com quem cuida da TI.

11 Por dentro do sistema

Você não precisa saber disto para usar o programa — mas se tiver curiosidade (ou precisar explicar para a TI), aqui está, em linguagem simples.

A ideia, com uma analogia de restaurante

O programa tem três partes que trabalham juntas, como numa cozinha:

🍳
A cozinha O Python + pandas lê o CSV e faz todas as contas (somas, médias, subtotais). É o motor de verdade.
→
🧑‍🍳
O garçom Um servidor local leva o seu pedido (“agrupe por produto”) até a cozinha e traz a resposta pronta. Atende só a sua máquina.
→
🪟
A vitrine A tela que você vê (feita com tecnologia de site) mostra a tabela e os gráficos dentro de uma janela de aplicativo.

É por isso que ele funciona tanto como aplicativo quanto no navegador: a “vitrine” é a mesma página; só muda a moldura em volta dela.

O que vem junto no programa

Tudo o que o Avesso precisa — o Python e todas as peças — vem embutido na própria pasta do programa (na subpasta _internal). Pense nela como uma caixa fechada: nada é instalado no Windows e nada bagunça o resto do computador. Se um dia você apagar a pasta do Avesso, nada mais no sistema é afetado. Dentro dela:

12 Dúvidas rápidas

Cliquei para abrir e apareceu “O Avesso já está aberto”

Ele já está rodando — o Avesso mantém só uma cópia aberta de propósito, para não deixar o computador lento. No modo navegador, mesmo que você tenha fechado a aba, ele continua ativo com um ícone na bandeja do Windows (ao lado do relógio): clique nesse ícone para abrir a aba de novo — não precisa de outra cópia. No modo aplicativo, a janela pode estar minimizada ou atrás de outra. Para fechar de vez, use Encerrar o Avesso no menu da bandeja (ou feche a janela).

Os acentos apareceram errados (Ã©, Ã§)

É a codificação. Na importação, troque Codificação para Windows-1252 ou UTF-8 (com BOM) e clique em Analisar de novo.

Os valores viraram texto / não somam

O separador decimal está trocado. Se seus números usam vírgula (1.234,56), escolha Vírgula em Separador decimal. Confira também se a coluna está marcada como Métrica.

“Sessão expirada. Reimporte os dados.”

O programa foi fechado ou reiniciado. Volte para a importação (← Voltar para importação), carregue o arquivo e confirme os campos novamente.

Quero começar do zero

Limpar áreas esvazia o cubo sem perder os dados importados. Para trocar de arquivo, use ← Voltar para importação.
